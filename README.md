# options-lab

European and American option pricing in Rust, as a library and a CLI.
Black-Scholes-Merton with a continuous dividend yield, all first- and
second-order Greeks, an implied-volatility solver that stays accurate in
the wings, Cox-Ross-Rubinstein trees for early exercise, a seeded Monte
Carlo pricer with antithetic and control variates, put-call parity checks,
and a smile builder that fits a quoted chain and draws it in the terminal.

No network access, no API keys, no unsafe code. Four runtime dependencies:
`clap` for the CLI and `rand`/`rand_chacha`/`rand_distr` for Monte Carlo.

## Quickstart

```sh
git clone <this repo> && cd options-lab
cargo build --release
./target/release/options-lab price --spot 100 --strike 105 --vol 0.2 --rate 0.03 --days 30 --type call
cargo test                       # 86 tests: unit, integration, reference values, properties, doctests
cargo run --example quickstart   # library tour
cargo bench                      # criterion benchmarks
```

Or install the binary: `cargo install --path .`

out-of-the-money side at every strike, fits a vega-weighted quadratic in

Chain format: `strike,type,bid,ask` (or a single `mid`/`price` column),
case-insensitive headers, extra columns ignored. Market data goes in
comment lines and can be overridden with `--spot`, `--rate`, `--div`,

strike; `--width`/`--height` size the chart; `--no-chart` prints only the
table.

## Library

```rust
use options_lab::binomial::BinomialTree;
use options_lab::monte_carlo::MonteCarlo;
use options_lab::{bsm, iv, OptionParams, OptionType};

let p = OptionParams::new(100.0, 105.0, 30.0 / 365.0)
    .with_rate(0.03)
    .with_dividend(0.0)
    .with_vol(0.20);

let price = bsm::price(OptionType::Call, &p)?;           // 0.695442
let g = bsm::greeks(OptionType::Call, &p)?;              // g.delta, g.vanna, g.volga, ...
let sol = iv::implied_vol(OptionType::Call, 0.85, &p)?;  // sol.vol = 0.217824, sol.method = Newton
let am = BinomialTree::american(1000).valuation(OptionType::Put, &p)?;
let mc = MonteCarlo { paths: 500_000, seed: 7, ..MonteCarlo::default() }
    .price(OptionType::Call, &p)?;                       // mc.price, mc.std_error, mc.confidence_95()
```

Every fallible function returns `options_lab::Result<T>`. Invalid inputs
(negative spot, NaN vol), arbitrage-violating quotes, non-converging solvers
and malformed CSV all surface as distinct `Error` variants instead of NaN
or panics.

## The math

**Black-Scholes-Merton** with continuous dividend yield `q`, `φ = +1` for
calls and `-1` for puts:

```text
d1 = [ln(S/K) + (r - q + σ²/2) T] / (σ√T),   d2 = d1 - σ√T
V  = φ [ S e^{-qT} N(φ d1) - K e^{-rT} N(φ d2) ]
```

When `σ√T` underflows the price is taken at its deterministic limit
`max(φ(S e^{-qT} - K e^{-rT}), 0)`, so expiring and zero-vol contracts do
not produce NaN.

**Greeks** (raw units; `n` is the standard normal density):

| Greek | Formula |
|---|---|
| delta | `φ e^{-qT} N(φ d1)` |
| gamma | `e^{-qT} n(d1) / (S σ √T)` |
| vega  | `S e^{-qT} n(d1) √T` |
| theta | `-S e^{-qT} n(d1) σ / (2√T) - φ r K e^{-rT} N(φ d2) + φ q S e^{-qT} N(φ d1)` |
| rho   | `φ K T e^{-rT} N(φ d2)` |
| vanna | `-e^{-qT} n(d1) d2 / σ` |
| volga | `vega · d1 d2 / σ` |

**Normal CDF.** Hart's double-precision rational approximation with a
continued-fraction tail (absolute error below 1e-14), not the usual
Abramowitz-Stegun 7.1.26, whose 1e-7 error is too coarse for wing implied
vols. Lower-tail values are computed directly, so `N(-10)` is
7.6e-24 rather than 0.

**Implied volatility.**
1. Reject quotes outside `(max(φ(S e^{-qT} - K e^{-rT}), 0), upper)`.
2. Map an ITM quote to the OTM option at the same strike through parity,
   so the target is pure time value with no cancellation.
3. Start from Corrado-Miller, or the Manaster-Koehler point
   `√(2|ln(F/K)|/T)` where Corrado-Miller's discriminant goes negative.
4. Run Newton on `ln(price)` instead of price. `ln(price)` is concave in σ
   (verified numerically for OTM options), so Newton converges monotonically
   from below, and in the wings, where price behaves like
   `exp(-k²/2σ²T)`, the log objective is close to linear. Every evaluation
   narrows a bracket; a step that would leave it is replaced by bisection.
5. If the Newton budget runs out, Brent's method finishes inside the
   bracket.

Over 366 round-trip cases (strikes 0.25x to 4x spot, 1 day to 5 years, 2%
to 300% vol) the mean is 6.4 iterations, the worst 13, and Brent was never
needed. Switching from the Manaster-Koehler start to Corrado-Miller dropped
the mean from 7.4. A test forces the Brent path to keep it covered.

**Cox-Ross-Rubinstein.** `u = e^{σ√Δt}`, `d = 1/u`,
`p = (e^{(r-q)Δt} - d)/(u - d)`; backward induction in a single `O(N)`
buffer, with `max(continuation, exercise)` at each node for American
exercise. Delta, gamma and theta are read from the first two steps. Trees
with `p` outside `(0, 1)` (too few steps for the carry) are an error.

**Monte Carlo.** Exact GBM terminal sampling, so no discretisation bias.
Antithetic pairs `(Z, -Z)`; the terminal spot as control variate with its
known mean `S e^{(r-q)T}` and `β = Cov(Y, X)/Var(X)` estimated from the
same samples. ChaCha8 seeded by a `u64` makes runs reproducible across
platforms. The standard error is a sample estimate, so it cannot see
events rarer than about `1/paths`: the property tests found a deep ITM call
where every path finished in the money and the reported error was 1e-10
against a true tail of 1.2e-7. That case is documented, not hidden.

**Smile fit.** `σ(k) = a + b k + c k²` on `k = ln(K/F)`, weighted least
squares with vega weights (a far-OTM quote with almost no vega carries
almost no information about σ), solved through 3x3 normal equations with
partial pivoting. A quadratic captures level, skew and curvature over the
quoted range; it is not arbitrage-free in extrapolation.

## Testing

`cargo test` runs 86 tests:

* **Reference values.** Price and all seven Greeks for calls and puts
  against scipy in eight regimes (spot 1.25 to 3500, one week to three
  years, 8% to 90% vol) at 1e-9 relative tolerance. Hull Example 15.6
  (4.7594 / 0.8086), Haug's Merton index put (2.4648), Hull's American put
  (4.4885 at 5 steps, 4.2830 at 500).
* **Finite differences.** Every analytic Greek against central differences
  of the price, for calls and puts.
* **Properties** (proptest): put-call parity, static no-arbitrage bounds,
  Greek signs, monotonicity in vol and strike, IV round-trips,
  American ≥ European ≥ intrinsic, Monte Carlo within five standard
  errors of BSM. All pass at 20,000 cases each
  (`PROPTEST_CASES=20000 cargo test --release --test properties`).
* **CLI.** The built binary is driven end to end, including error exits.

## Performance

`cargo bench` on an Apple M2, release profile with thin LTO:

| Benchmark | Time |
|---|---|
| BSM price | 33 ns |
| BSM price + 7 Greeks | 38 ns |
| Implied vol, ATM 6m | 0.27 µs |
| Implied vol, 30d 10% OTM call | 0.97 µs |
| Implied vol, 60% OTM 1y put | 1.2 µs |
| CRR American put, 100 / 500 / 2000 steps | 7.9 µs / 0.21 ms / 3.1 ms |
| Monte Carlo 100k paths, plain | 2.1 ms |
| Monte Carlo 100k paths, antithetic + CV | 1.5 ms |
| Parse 42-quote chain + 18 IVs + fit | 22 µs |

Antithetic sampling is faster than plain at the same path count because it
draws half as many normals.

## Layout

```text
src/
  lib.rs            crate root and re-exports
  types.rs          OptionType, ExerciseStyle, OptionParams (+ validation)
  error.rs          Error enum shared by all modules
  math.rs           normal pdf/cdf
  bsm.rs            Black-Scholes-Merton price and Greeks
  iv.rs             implied volatility (log-Newton + Brent)
  solver.rs         Brent's method
  binomial.rs       Cox-Ross-Rubinstein tree
  monte_carlo.rs    seeded Monte Carlo with variance reduction
  parity.rs         put-call parity, implied forward and dividend
  smile/
    chain.rs        chain CSV parser
    fit.rs          weighted quadratic fit
    chart.rs        ASCII chart
    mod.rs          smile builder
  main.rs, cli/     clap front end; formatting only, no numerics
tests/              CLI, reference-value and property tests
benches/            criterion benchmarks
examples/           quickstart, synthetic chain generator, chain.csv
```

The library has no I/O. The CLI parses arguments, calls the library and
formats tables.

## Roadmap

* SVI and SSVI smile parameterisations with static-arbitrage checks
  (butterfly and calendar), replacing the quadratic for wide strike ranges.
* Discrete cash dividends (escrowed-dividend model in BSM, dividend-adjusted
  nodes in the tree).
* Jäckel's "Let's Be Rational" as an alternative IV backend, for a
  guaranteed two-iteration solve.
* Path-dependent Monte Carlo (Asian, barrier) with Brownian-bridge
  correction, and Sobol sequences for quasi-random sampling.
* Multi-expiry chains and a term-structure view in `smile`.
* Optional `serde` output (`--json`) for piping into other tools.
